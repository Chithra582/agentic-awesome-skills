# AAS Catalog Search

## Overview
Enables developer agents to search the complete offline AAS playbook catalog across 2,400+ standardized skills, matching user intentions with concrete automation playbooks.

## Key Capabilities
- Full-text search across skill titles, descriptions, and compatibility tags.
- Framework-specific targeting for Claude Code, Cursor, Codex, and Antigravity.
- Offline-first execution without external telemetry dependencies.
