# Stack Validation Harness

## Overview
Performs non-destructive environment audits to verify that all necessary compilers, interpreters, and CLI utilities required by a skill are operational in the target environment.

## Key Capabilities
- Language version detection (Node.js, Python, Go, Rust).
- Container runtime verification (Docker, Podman).
- Non-destructive execution ensuring zero environmental side effects.
